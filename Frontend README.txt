The Figma design was connected  to a React frontend built with JavaScript, HTML, and CSS, where each UI components to match the original design of the high fidelity wireframe . The React side handles user input for transaction data and formats it into JSON before sending it to the FastAPI backend. This data is sent to the /assess_transaction/ endpoint, where FastAPI uses Pydantic 
a python library)  to validate the incoming data, making sure everything matches the required structure and data types before anything is processed. After validation, the backend runs the data through a rule-based system and the XGBoost fraud detection model, then combines both results using a weighted ensemble to produce a final risk score and classification. The frontend then receives the response and updates the UI in real time to show the result. The other pages (show in the sidebar) in the React app also connect to endpoints like /transactions/, /settings/, and /analytics/,so it displays stored data, update system settings, and show dashboard statistics from the MySQL database.
